# Ponnana Rohit — Developer Portfolio

My personal developer portfolio built with React, Vite, Tailwind CSS, TypeScript, and Lucide Icons.

The complete application is located in the [`portfolio`](./portfolio) directory.

### Quick Start

```bash
cd portfolio
npm install
npm run dev
```

For full documentation, architecture breakdown, and deployment guides, see the [portfolio README](./portfolio/README.md).
